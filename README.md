# Practical assessment：距离数字密码锁

把**超声波测得的距离数字直接当作密码**。默认三段密码是 **15 → 25 → 35 cm**：依次把平整纸板或手掌放在这些位置，每到一个位置按 **A** 记录，最后按 **C** 确认。记录错误时按 **B** 撤销最后一个数字。OLED 显示当前距离及已录入的三个数字；密码正确时 9g 舵机开锁 5 秒，再自动上锁。

主程序：[DistancePasswordLock/DistancePasswordLock.ino](DistancePasswordLock/DistancePasswordLock.ino)，**180 行**。它在原三按钮 OLED 舵机密码锁上改进，将机械按键选数字改为“真实距离产生数字”，传感器测量值直接决定执行器动作。按钮采用 `INPUT_PULLUP`，**外接电阻 0 个**。不再输入摩斯密码。

## 输入规则

| 目标数字 | 可以接受的实测值（±3 cm） |
|---|---|
| 15 cm | 12–18 cm |
| 25 cm | 22–28 cm |
| 35 cm | 32–38 cm |

每次按 A 时，程序**重新测距三次并取中间值**，随后把测得的整数厘米数记入密码。屏幕会显示实际记录值，例如 `16 24 34` 也能开锁。无回波或超出有效测量范围（5–80 cm）时显示 `NO ECHO`，不记录。未录够三个数字就按 C 显示 `NEED 3`。连续三次输错显示 `WAIT 30s`，暂停 30 秒。可修改代码中的 `password[3]` 和 `toleranceCm` 换成自己的密码及误差范围。

## 元件和接线

使用现有 Arduino Uno R3、128×64 四针 I²C OLED、三个按钮、9g 舵机，增加套件里的 HC-SR04 超声波模块。参见[接线图.svg](接线图.svg)。接线前断开 USB。

| 元件 | 连接 |
|---|---|
| A：记录当前距离 | 按钮一侧接 D2，另一侧接 GND |
| B：撤销最后一个数字 | 按钮一侧接 D3，另一侧接 GND |
| C：确认密码 | 按钮一侧接 D4，另一侧接 GND |
| HC-SR04 `TRIG`、`ECHO` | D6、D7 |
| HC-SR04 `VCC`、`GND` | Uno 5V、GND |
| OLED `SDA`、`SCL` | Uno A4、A5 |
| OLED `GND` | Uno GND |
| OLED `VCC` | 按模块标称电压接 3.3V 或 5V；沿用此前能正常亮屏的接法 |
| 舵机信号线（通常黄/橙） | D9 |
| 舵机红线 | 外部稳定 5V 正极，建议电源至少 1A |
| 舵机地线（通常棕/黑） | 外部 5V 负极，且**必须接 Uno GND 共地** |

四脚按钮应选按下才导通的两侧脚，同一侧两脚本来连通。面包板不同排不相通，电源轨中间也可能断开。不要用 Uno 的 5V 引脚直接给舵机供电。OLED 默认 SSD1306 地址 `0x3C`；如模块实际地址为 `0x3D`，修改源码 `screen.begin(...)` 的地址。

## 一分钟演示

1. 上电，OLED 显示 `DISTANCE LOCK` 和实时厘米数。用平整纸板对准 HC-SR04，在 15 cm 左右按 A，OLED 显示第一项。
2. 将纸板移到 25 cm 左右按 A，再移到 35 cm 左右按 A。屏幕显示三组实测数字。
3. 按 C，屏幕显示 `OPEN 5s`，舵机转动后自动回原位。
4. 再输入一组明显不同的距离，例如 15、15、15 cm，按 C，显示 `WRONG` 且舵机不转。若录错一个数字，按 B 撤销后重新录入。

先不装锁舌，单独确认舵机的 `lockedAngle = 0` 与 `openAngle = 90` 不会让机械结构卡住。按 A 时保持纸板相对静止约 0.2 秒，让三次测距稳定。Arduino IDE 请选择 **Arduino Uno** 与实际串口，打开 `DistancePasswordLock.ino` 上传；需要已安装 Adafruit GFX、Adafruit SSD1306、Adafruit BusIO、Servo 库，Wire 是 Arduino 自带库。
